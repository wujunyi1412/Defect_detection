# 技术交底书

## 一、发明名称

一种融合监督分割与异常检测的工业缺陷协同检测方法及系统

## 二、背景技术

### （一）现有技术

工业外观检测通常采用监督检测和异常检测两类方法。

监督检测方法需要预先采集并标注缺陷样本，再利用目标检测或实例分割模型进行训练。模型上线后可以输出缺陷类别、置信度、检测框和分割区域。这类方法能够识别训练数据中已经定义的缺陷，但检测范围受到训练样本和标签类别的限制。

异常检测方法主要使用正常产品图像建立特征库。检测时，将待测图像的局部特征与正常特征进行比较，根据两者之间的差异生成异常分数和异常区域。这类方法可以发现没有预先定义的异常，但一般只能输出通用异常，难以直接给出明确的业务缺陷类别。

现有系统也可以同时运行监督模型和异常模型，但较直接的做法通常是分别推理后合并结果。由于两个模型的输出形式和分数含义不同，简单合并不能形成稳定的协同检测结果。

### （二）现有技术存在的问题

1. 监督模型依赖已标注样本，对样本不足或没有预先定义的新异常容易漏检。

2. 异常模型虽然能够补充发现未知异常，但不能直接给出明确的业务缺陷类别。

3. 同一个物理缺陷可能同时被监督模型和异常模型检出，直接合并会造成重复计数。

4. 两个模型的输出形式不同。监督模型输出类别、检测框、置信度和分割区域，异常模型输出图像级异常分数和异常分数图，两类结果不能直接比较。

5. 异常模型容易把黑边、无效视场或固定结构识别为异常，而这些位置又可能是监督模型需要检查的区域，因此两个模型不适合完全采用相同的图像预处理。

6. 单纯依靠模型分数难以排除反光、亮度不均和局部噪声。暗缺陷和亮缺陷的灰度变化方向相反，也不适合使用同一对比度条件。

7. 异常模型可能把多个按规则排列的异常单元输出为一个整体异常区，不能直接满足数量统计和工艺追溯要求。

### （三）背景技术来源说明

上述监督检测、实例分割、基于正常样本的异常检测和多模型组合均属于公开使用的技术。目前没有指定某一篇专利、期刊或书籍作为最接近的现有技术来源。项目中使用的具体模型和软件框架只代表一种实现方式，不构成本方案的必要限制。

## 三、发明内容及有益效果

### （一）要解决的技术问题

本方案主要解决以下技术问题：

1. 如何同时识别具有明确类别的已知缺陷和训练标签以外的未知异常；

2. 如何针对两个模型不同的敏感特性分别进行图像预处理；

3. 如何将两类模型的不同输出转换为可以统一过滤和统计的缺陷结果；

4. 如何消除两个模型对同一物理缺陷的重复报告；

5. 如何结合缺陷面积、尺寸和明暗对比度降低模型误报；

6. 如何将异常模型输出的通用异常转换为客户端可以直接使用的分类结果。

### （二）总体技术方案

本方案从同一待测图像生成两路模型输入。第一路输入用于监督分割模型，识别具有明确类别的已知缺陷；第二路输入用于基于正常样本的异常检测模型，补充发现监督模型未能识别的异常。第二路输入还会屏蔽无效边缘，以减少异常模型对黑边和无效视场的误报。

两个模型完成推理后，将各自结果统一转换为缺陷区域、面积、位置、对比度和模型分数等缺陷明细。监督模型结果按照类别对应的置信度、面积、尺寸和对比度条件进行过滤；异常模型结果按照异常分数和异常面积的组合条件进行过滤。

过滤完成后，计算通用异常结果与具体类别结果之间的空间重叠关系。当两个结果对应同一物理区域时，删除通用异常，保留具有明确类别的监督模型结果；没有与具体缺陷重叠的异常结果继续保留，用于补充监督模型未发现的异常。

最后，将保留结果归并为预设业务类别，并输出缺陷类别、数量、面积、对比度和位置等信息。结构化结果和标注图像使用同一份最终缺陷明细生成。

### （三）主要创新点及对应效果

1. 双模型分工协同。

技术特征：监督分割模型负责识别具有明确类别的已知缺陷，正常样本异常模型负责补充发现未定义异常。

解决的问题：单一监督模型不能覆盖未知异常，单一异常模型又不能提供明确类别。

有益效果：在保留缺陷分类能力的同时扩大异常检测范围。

2. 两个模型采用差异化图像预处理。

技术特征：监督分割支路保留有效视场，异常检测支路单独屏蔽无效边缘。

解决的问题：异常模型容易将黑边或无效视场识别为异常，但监督模型仍可能需要检测边缘附近的已知缺陷。

有益效果：在不缩小监督模型检测范围的情况下减少异常模型的边缘误报。

3. 两种模型结果统一量化。

技术特征：把监督模型的检测框和分割区域，以及异常模型的异常分数图，统一转换为至少包含缺陷区域、面积、位置、对比度和分数的缺陷明细。

解决的问题：两类模型的原始输出形式和含义不同，不能直接融合。

有益效果：两种结果可以使用同一套规则进行过滤、比较、去重和统计。

4. 异常分数与异常面积联合判断。

技术特征：异常分数达到较高阈值时直接保留；异常分数达到较低阈值时，还需要异常面积比例达到设定阈值。

解决的问题：单一异常分数阈值难以同时检测小面积强异常和大面积中等异常。

有益效果：兼顾不同面积和不同异常程度的缺陷。

5. 根据缺陷明暗极性计算对比度。

技术特征：根据缺陷类别选择亮极性、暗极性或自动极性，并结合缺陷周围背景及稳健统计量计算对比度。

解决的问题：模型高分结果可能由反光、亮度不均或噪声造成，亮缺陷和暗缺陷也不能采用相同的灰度判断方向。

有益效果：利用缺陷与背景之间的实际灰度关系复核模型结果，降低误报。

6. 跨模型空间去重。

技术特征：计算通用异常区域与具体类别缺陷区域之间的空间重叠程度；满足重复条件时删除通用异常，保留具体类别结果。

解决的问题：同一物理缺陷被两个模型重复报告。

有益效果：避免重复计数，并优先保留信息量更高的缺陷类别。

### （四）进一步的技术特征

1. 对指定缺陷类别，可以在模型区域内采用种子提取、区域生长、形态学处理和连通域筛选，重新确定缺陷范围并计算面积和对比度。

2. 对规则排列的异常连通域，可以分别对横坐标和纵坐标聚类，并根据区域数量及间距关系将整体异常拆分为多个单元异常。

3. 模型内部细分类别可以通过配置归并为稳定的业务类别，避免模型类别与客户端类别直接绑定。

4. 两个模型可以并行或异步交叠运行；其中一个模型失败时，可以继续使用另一个模型的有效结果。

5. 结构化结果和标注图像由同一份最终缺陷明细生成，保证统计结果与图像标注一致。

## 四、具体实施例

### （一）系统组成

系统包括图像预处理模块、监督分割模块、异常检测模块、结果量化模块、结果融合模块和结果输出模块。

图像预处理模块分别与监督分割模块和异常检测模块连接。两个模型的输出进入结果量化模块，转换为统一缺陷明细；统一缺陷明细进入结果融合模块，完成过滤、空间去重和类别归并；最终结果进入输出模块，生成结构化数据和标注图像。

### （二）具体处理步骤

1. 获取待测图像。

待测图像可以是灰度图、彩色图、浮点图、相机缓冲区或图像文件。当前工程接收单通道浮点数组，但输入格式不构成限制。

2. 生成两路模型输入。

将待测图像转换为两个模型所需的尺寸和通道格式。监督分割支路保留有效视场；异常检测支路检测并屏蔽无效边缘区域。

3. 执行双模型推理。

监督分割模型输出缺陷类别、置信度、检测框和分割区域。异常检测模型提取待测图像的局部特征，将其与正常样本特征库进行比较，输出异常分数图和图像级异常分数。

两个模型可以交叠运行。两个模型均成功时融合两类结果；仅一个模型成功时继续处理有效结果；两个模型均失败时返回检测失败。

4. 统一量化两种结果。

根据监督模型的分割区域计算缺陷面积，并保留检测框、类别和置信度。对异常分数图进行阈值化、补边裁除和原图尺寸映射，计算异常面积和外接框。

结合缺陷区域和周围背景计算对比度。暗缺陷选取偏暗像素统计，亮缺陷选取偏亮像素统计，极性不确定时根据缺陷相对背景的变化方向自动判断。

5. 分别过滤两类结果。

监督模型结果按照类别对应的置信度、对比度、最小宽度、最小高度和最小面积过滤。

异常模型结果采用以下条件过滤：异常分数达到第二阈值时直接保留；或者，异常分数达到第一阈值且异常面积比例达到面积阈值时保留。

6. 执行跨模型去重。

计算通用异常框和具体类别缺陷框之间的交并比。交并比大于设定阈值时，认定两个结果对应同一物理缺陷，删除通用异常并保留具体类别结果。未与具体缺陷重叠的异常继续保留。

该步骤在类别过滤之后、最终计数之前执行，避免无效结果参与去重，也防止重复结果进入最终统计。

7. 归并类别并输出。

将模型内部类别映射为业务类别，输出缺陷类别、数量、面积、对比度和位置。当前工程将结果归并为 Abnormal、Stain、BrightClusters、GlueOverflow、Decolorization 和 LineArtifacts 六类，但类别数量、名称和映射关系均可以调整。

### （三）缺陷范围修正实施例

对于模型边界不准确的缺陷，在模型框内估计局部背景并计算缺陷响应。先采用严格阈值得到种子区域，再采用宽松阈值扩展区域，经过形态学处理和连通域筛选后重新计算缺陷框、面积和对比度。修正结果不可靠时，保留模型原始范围。

### （四）规则阵列异常拆分实施例

当异常区域包含多个连通域时，选取主要连通域，分别对中心点的横坐标和纵坐标进行聚类。以三行三列结构为例，检查每个横向分组和纵向分组是否均包含三个区域，并检查相邻行、列之间的间距是否近似一致。验证通过后，将整体异常拆分为九个单元异常；验证不通过时仍按整体异常输出。

### （五）替代方案

1. 监督分割模型可以替换为其他目标检测、实例分割或语义分割模型。

2. 异常检测模型可以替换为其他基于正常样本、特征距离或重构误差的方法。

3. 跨模型去重可以采用检测框交并比、掩膜重叠率、中心距离、包含关系或其组合。

4. 对比度背景可以采用局部背景环、自适应局部平面或全视场统计。

5. 三行三列结构可以扩展为 M 行 N 列或其他具有空间先验的重复结构。

6. 输出可以采用数组、结构体、共享内存、数据库记录或其他结构化形式。
